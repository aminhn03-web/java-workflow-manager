# Java Workflow Manager
A Java task and workflow management application developed through Test-Driven Development and a feature-branch Git workflow.

## Learning Objectives
- Write idiomatic, maintainable Java.
- Practice TDD, object-oriented design, and SOLID principles.
- Use manual constructor injection.
- Develop professional Git, code review, and CI habits.

## Current status
Initial project setup. No application features are implemented yet.

## Technology
- Java 25
- Maven
- Eclipse IDE

## Build and test
Maven validation has succeeded through Eclipse.
Command-line builds and automated testing are not yet configured.
Reproducible build and test instructions will be added during setup.

## Project structure
- 'src/main/java' - application source code
- 'src/main/resources' - application resources
- 'src/test/java' - automated tests
- 'src/test/resources - test resources
- 'pom.xml' - Maven project and build configuration
